# Stack Expression Compiler & Calculator

Учебный проект по алгоритмам: стековый компилятор выражений и интерпретатор на Python.

В репозитории сохранены две версии задания, каждая расширяет базовый стековый компилятор отдельной функциональностью.

## 1. `octal/` - восьмеричные литералы

- токенизация выражения;
- числа в формате `0o...` / `0O...`;
- преобразование восьмеричных значений в десятичные;
- проверка допустимого диапазона;
- стековая обработка операторов и скобок;
- набор тестов на корректные выражения и ошибки.

Пример:

```python
Compf().compile("(0o12+0o13)*0o2")
# "10 11 + 2 *"
```

## 2. `bitwise/` - побитовые сдвиги

- стандартные арифметические операции;
- операторы `<<` и `>>`;
- приоритеты операций и скобки;
- интерпретация выражений через стековый калькулятор;
- автоматические тесты.

Пример:

```python
Calc().compile("(1<<2)>>1")
# 2
```

## Запуск тестов

```bash
cd octal
PYTHONPATH=. pytest -q

cd ../bitwise
PYTHONPATH=. pytest -q
```

В подготовленной версии оба набора тестов проходят полностью.
